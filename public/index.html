Where things live

How sources connect

Getting help

Three specialist agents and a Controller work on the same map.
Staying in control
You copy and paste results across yourself.
Every agent action waits for Approve or Reject, and agents earn or lose score.
Trying an idea

A what-if drawer shows predicted accuracy, latency and memory as you drag a slider (simulated).
Remembering how you got here

Working offline

Sharing
Screenshots and pasted links.
One Markdown or JSON export with notes, relationships and experiments.

Where tabs still win. Reading one paper start to finish is better in a PDF viewer. MYCELIA keeps the summary, the tags and the links; you keep the PDF. Experiments here are simulated, so treat the numbers as a guide for what to try next, not as results.
